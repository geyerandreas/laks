# A self-hosted Python package registry

Laks is an early-stage project for hosting Python packages and managing the
accounts that can access a private registry. The repository contains a Rust
backend and a Nuxt web interface.

The project is under active development. Authentication and user management are
present, but package publishing and several dashboard features are not yet
complete. Treat the current application as a development build, not a
production-ready private registry.

## What is here today

- A Rust/Axum service with SQLite-backed users and package metadata, plus
  filesystem package storage.
- A Vue/Nuxt interface with account registration and sign-in.
- A user-management screen backed by the service API.
- Initial Python Simple Repository API routes.
- An OpenAPI document and Swagger UI served by the backend.

The package dashboard currently displays sample data. The registry upload,
index, and download path is still being developed; see
[Python packages](/essentials/python-packages) for the current limitations.
