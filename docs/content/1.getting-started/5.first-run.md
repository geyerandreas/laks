After starting the backend and UI, visit `http://localhost:3000`.

## Sign in or create an account

Use the initial administrator credentials configured in `laks.toml` to sign in.
The registration page can also create a regular user account; newly registered
accounts are not administrators.

The UI checks the session through the backend and sends authenticated browser
requests with cookies. Signing out clears the session cookie.

## Current interface

- **Dashboard:** package metrics and rows are hard-coded sample data, not live
  registry statistics.
- **Users:** lists, creates, edits, and deletes users using the backend API.
- **Inbox and Customers:** empty-state screens without data integrations.
- **Notification and Security settings:** placeholder screens.
- **Package row actions:** some actions are visual placeholders and are not
  connected to backend operations.

For registry behavior and its current status, see
[Python packages](/essentials/python-packages).

## Important deployment warning

The backend currently does not enforce authentication on the user-management
and registry routes. The UI's sign-in checks are not a substitute for backend
authorization. Do not expose this development build to untrusted networks or
use it to protect real packages or user data.
