The repository is a Rust workspace with separate Nuxt applications for the
product UI and its documentation.

| Path                  | Purpose                                          |
| --------------------- | ------------------------------------------------ |
| `crates/laks/`        | Axum server, CLI, routes, and OpenAPI definition |
| `crates/auth/`        | Password verification and JWT support            |
| `crates/db/`          | SQLite access and database migrations            |
| `crates/settings/`    | CLI configuration and runtime settings           |
| `crates/storage/`     | Local filesystem-backed object storage           |
| `crates/appstate/`    | Shared backend application state                 |
| `ui/app/pages/`       | File-based routes for the Laks web interface     |
| `ui/app/composables/` | Shared authentication and dashboard state        |
| `docs/content/`       | Product and developer documentation              |

The UI is a Nuxt 4 app using Vue 3, TypeScript, and Nuxt UI. It calls the Rust
service under `/api/v1`; the backend serves generated OpenAPI documentation at
`/api/docs` and its specification at `/api/openapi.json`.

The backend uses SQLite by default (`./laks.sqlite`) and stores uploaded files
under `./storage`. Both paths can be changed through `laks.toml`.
