The dashboard shell includes navigation for the dashboard, inbox, customers,
and settings. Its package summary, download counts, storage figures, and
package rows are currently static examples in the UI source; they do not
represent values fetched from the backend.

The inbox and customers pages currently show empty states. Notification and
security settings are placeholders. The Users page is the main settings feature
connected to the API: it can list users and create, update, or delete accounts.

The package row menu includes unfinished actions. Do not use the dashboard as
an operational view of published packages yet.

For sign-in and the first administrator, see
[First run](/getting-started/first-run).
