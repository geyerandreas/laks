The backend creates an initial administrator account when it starts against a
database with no users. The name, email, and password are configured in the
`[setup]` section of `laks.toml`.

The web registration form creates a non-administrator account. Login sets an
HTTP-only `auth_token` cookie; the session status endpoint validates it, and
logout clears it. Passwords are stored as hashes.

## Authorization is not complete

The UI has route middleware that redirects signed-out visitors to the login
page, but the backend currently does not require authentication on its
user-management or registry routes. The UI checks are only a navigation
convenience and do not protect the API. Do not expose this build to untrusted
networks or use it for real accounts or package access.

See [First run](/getting-started/first-run) for setup details and the deployment
warning.
