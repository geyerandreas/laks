With the backend running locally, open:

- Swagger UI: `http://localhost:8080/api/docs`
- OpenAPI JSON: `http://localhost:8080/api/openapi.json`

The current API groups include:

| Prefix                           | Purpose                                         |
| -------------------------------- | ----------------------------------------------- |
| `/api/v1/health/health`          | Health check                                    |
| `/api/v1/auth/`                  | Registration, login, session status, and logout |
| `/api/v1/users/`                 | User management                                 |
| `/api/v1/registry/simple/`       | Initial Python Simple Repository API routes     |
| `/packages/{project}/{filename}` | Package-file download route                     |

The routes and workflows are still in development. In particular, registry
upload and retrieval are not complete; see
[Python packages](/essentials/python-packages). Backend authorization is also
not yet enforced for user-management and registry routes; see
[Accounts and authentication](/essentials/accounts-and-authentication).
