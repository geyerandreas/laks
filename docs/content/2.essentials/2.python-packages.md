Laks includes initial routes for the Python Simple Repository API under
`/api/v1/registry/simple/`. The routes are intended to list projects, show
project files, and accept package uploads.

## Current limitations

Package workflows are not complete end to end. The upload handler does not yet
persist the package-file records consumed by the project index, and the package
download path is not yet integrated with uploads. The web dashboard also uses
sample package and metric data.

As a result, do not rely on Laks as a working `pip` index or use `twine` to
publish production packages. Client-facing package installation and publishing
instructions will be added when those flows are implemented and verified.

The registry endpoints are described in the generated
[API reference](/essentials/api).
